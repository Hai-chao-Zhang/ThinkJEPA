# V-JEPA2 encoder source subset

This directory contains the V-JEPA2 encoder and utility files used by
ThinkJEPA training and cache reconstruction. See the upstream project for the
complete repository.

Upstream project: <https://github.com/facebookresearch/vjepa2>

Included source files:

```text
src/masks/utils.py
src/models/vision_transformer.py
src/models/utils/modules.py
src/models/utils/patch_embed.py
src/models/utils/pos_embs.py
src/utils/tensors.py
```

The upstream `LICENSE` and `APACHE-LICENSE` files in this directory apply to
the included source.
